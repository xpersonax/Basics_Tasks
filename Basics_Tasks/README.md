# Домашнє завдання: базові операції C#

Чотири окремі консольні програми в одному рішенні `Basics_Tasks.sln`.
Сторонні бібліотеки не використовуються, лише стандартний .NET (System).

| Проєкт | Завдання |
|---|---|
| Task1_ReverseNumber | Ціле число в зворотному порядку зі збереженням знака |
| Task2_RemoveWords | Видалення перших X слів із тексту |
| Task3_ShapeArea | Площа квадрата, круга, прямокутника або трикутника |
| Task4_ReplaceChars | Заміна кожного 3-го символу на X, 5-го на 9, 15-го на ? |

## Запуск
Visual Studio: відкрити `Basics_Tasks.sln`, ПКМ на потрібному проєкті → «Назначить запускаемым проектом» → F5.
Термінал: `dotnet run --project Task1_ReverseNumber` (так само для інших).

## Перевірені приклади
- Завдання 1: `123` → `321`, `1000` → `1`, `-453` → `-354`, `12345` → `54321`.
  Цифри перевертаються як рядок, тому програма працює з числами будь-якої довжини
  (5 цифр і більше, навіть довші за `long`). Короткі числа з прикладів теж приймаються.
- Завдання 2: `Hello big world` + `2` → `world`; `Nice red car and green eyes` + `4` → `green eyes`.
- Завдання 3: квадрат 2.5 → 6.25; круг 3 → 28.2743; прямокутник 3 і 4.5 → 13.5; трикутник 6 і 2,1 → 6.3.
  Дробові числа можна вводити через крапку або кому.
- Завдання 4: `Hello nice red car and green eyes` → `HeXl9XniX9 Xed?caX 9Xd X9eXn ?yeX`.
  Позиції рахуються з 1, пробіли теж символи; 15-й символ ділиться і на 3, і на 5, тому перевіряється першим.
